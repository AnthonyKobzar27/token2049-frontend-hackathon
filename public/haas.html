Payments

x402 payments on Cardano and Solana

The agent asks, gets a price back, pays on chain and gets the service. No accounts, no API keys.

x402

The endpoint answers with HTTP 402 and a price. The agent pays, retries, and the work starts. One request, one payment, no sign-up.

Cardano

USDM and USDCx settle through Masumi: escrow, refunds, disputes and agent identity, with a Veridian credential for verified workers.

Solana

The same flow with USDC on Devnet and Mainnet Beta. Switch chains with one config setting. Funds release only after the verifier passes the result.
